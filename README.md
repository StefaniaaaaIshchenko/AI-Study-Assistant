# AI Study Assistant

Веб-додаток для самостійного навчання з AI-помічником. Студент вписує тему або завантажує свій PDF-конспект і отримує пояснення, конспект, тест, флеш-картки та персональний план навчання.

Курсова робота · Іщенко Стефанія · 2026

## Структура застосунку

Застосунок поділено на три частини:

| Частина | Папка | Технології | Опис |
| --- | --- | --- | --- |
| Клієнтська | [`frontend/`](frontend/README.md) | HTML, CSS, JavaScript, PDF.js | Інтерфейс у браузері |
| Серверна | [`backend/`](backend/README.md) | PHP 8, mysqli, cURL | API, авторизація, звернення до OpenAI |
| База даних | [`database/`](database/schema.sql) | MySQL 8 | Структура 6 таблиць |

```
ai-study-assistant/
├── index.html            # перенаправлення на frontend/index.html
├── frontend/             # клієнтська частина
├── backend/              # серверна частина + документація API (OpenAPI/Swagger)
└── database/
    └── schema.sql        # структура бази даних
```

## Швидкий запуск (MAMP)

1. Скопіюй папку проєкту в `/Applications/MAMP/htdocs/ai-study-assistant`.
2. Запусти MAMP (Apache + MySQL).
3. У phpMyAdmin імпортуй `database/schema.sql` (або нічого не роби: таблиці створяться автоматично під час першого запиту).
4. Скопіюй `backend/config.example.php` у `backend/config.php` і впиши ключ OpenAI.
5. Відкрий http://localhost:8888/ai-study-assistant/

Документація API: http://localhost:8888/ai-study-assistant/backend/docs.html

## Основні можливості

- Реєстрація та вхід (PHP-сесії, паролі у вигляді bcrypt-хешу)
- Завантаження навчальних матеріалів (PDF, TXT)
- AI-помічник: пояснення теми, конспект, тест, відповідь на запитання; 3 рівні складності
- Флеш-картки з мнемонічними асоціаціями та колекціями
- План навчання на 2 тижні та підготовка до іспиту
- Статистика прогресу та оцінка сайту
